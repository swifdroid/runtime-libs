- `build.gradle.kts` - root Gradle configuration
- `gradle.properties` - Gradle properties

- `foundation/` - Foundation runtime AAR module
- `foundationessentials/` - FoundationEssentials runtime AAR module
- `i18n/` - internationalization runtime AAR module
- `networking/` - networking runtime AAR module
- `testing/` - testing runtime AAR module
- `xml/` - XML runtime AAR module
- `copy-so-files.sh` - runtime-library ingestion helper
- `jitpack.yml` - hosted build configuration
- `CHANGELOG.md` - public release history
- `README.md` - public repository usage/overview

Use this map before broad discovery. It is navigation, not proof that every listed module/path is unchanged from the current working tree.
