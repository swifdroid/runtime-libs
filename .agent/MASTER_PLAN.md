# Master Plan

Repository-level capability roadmap for `core-libs`.

1. Keep Swift Android runtime AAR modules aligned with supported Swift toolchain releases.
2. Keep runtime ingestion reproducible and auditable.
3. Keep Gradle/AAR/JitPack packaging coherent for downstream consumers.
4. Strengthen representative consumer verification for integration-sensitive runtime changes.
5. Keep release/changelog documentation synchronized with verified shipped runtime changes.

This is direction, not proof that a specific version/update is approved or implemented. Executable work belongs in `TASKS.md`.
